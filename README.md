An executive, high-performance personal developer portfolio built with **React**, **Vite**, **Tailwind CSS**, and **GSAP**. Features dynamic API stats, tabbed work experience proof lightboxes, interactive credentials gallery, and dark cyber aesthetics.

---

## ✨ Key Features

- **⚡ Interactive GSAP Intro Splash Loader**: SVG path stroke outline + wipe fill animation rendering *"ABHINAM KUMAR MAHATO"*.
- **📊 Live Dynamic Coding Stats**: Real-time REST API integration fetching live solved problem counts from **LeetCode** (`alfa-leetcode-api`) and **GeeksforGeeks**.
- **💼 Executive Work Experience Showcase**: Tabbed internship interface with official company logos (**Tata Steel Limited**, **CSIR–CIMFR**, **AutoCluster Adityapur**) and high-res click-to-expand photo proof lightboxes.
- **💻 Featured Projects Suite**: Categorized projects grid with filter pills (*InstantTool Smart Passport AI*, *Rockguard AI Hazard Dashboard*, *Tata Steel Samadhan App*, *UCG Simulator*).
- **📜 Interactive Certifications Gallery**: High-res Lightbox modal preview for verified certificates from **IBM**, **FreeCodeCamp**, **Ranchi Hacks 2026**, **Asian Paints**, **Nestle**, and **Unstop**.
- **📱 Screen-Fitted Responsive Design**: Fully responsive across mobile, tablet, laptop, and 4K displays with sticky glassmorphic navigation bar.

---

## 🛠️ Tech Stack & Dependencies

- **Core**: React 19, JavaScript (ES6+)
- **Build Tool**: Vite
- **Styling**: Tailwind CSS, Vanilla CSS, Glassmorphism
- **Animations**: GSAP (GreenSock), AOS (Animate On Scroll), Typewriter Effect
- **Icons**: Lucide React
- **Form Service**: GetForm.io
- **APIs**: LeetCode Solved API, GeeksforGeeks API

## 💻 Local Project Setup

### Prerequisites
Make sure you have **Node.js** (v18+) installed on your machine.

### Installation Steps

1. **Clone the Repository**
   ```bash
   git clone https://github.com/AbhiMahto/PortFolio.git
   cd PortFolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser to view the application.

4. **Build for Production**
   ```bash
   npm run build
   ```
